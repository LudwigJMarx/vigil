# Code of conduct

## The short version

Talk to people the way you would want a maintainer to talk to you when you have
just filed a bad bug report. Argue with the change, not with the person who
wrote it.

## What is expected

- Review the diff, not the author
- Say what is wrong and what would be right, in the same message
- Assume the other person had a reason, and ask what it was before assuming
  there was none
- Accept that "no" with a reason is a complete answer

## What is not accepted

Harassment, insults, and personal or political attacks. Sexualised language or
imagery. Publishing someone's private information. Sustained disruption of
discussions.

## Enforcement

Report to the address in the repository owner's GitHub profile. Reports are
handled privately.

Responses are proportionate and escalate: a correction, a warning, a temporary
ban, a permanent ban. The maintainer decides, and says which one applies and
why.

## Scope

Issues, pull requests, discussions and commit messages in this repository, and
anywhere someone is representing the project.
